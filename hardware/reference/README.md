# Reference material

Drop board/datasheet reference here — pinout diagrams, schematics, datasheets, photos.
Claude can read images (PNG/JPG) and PDFs directly from this folder.

Useful drops:
- ESP32-S3-AMOLED-1.91 pinout diagram (the 2×20 header image) + schematic PDF
- CS43131 / DRV2605L / LT3042 / MAX17048 datasheets
- Board photos (front/back silkscreen)

Large binaries are fine locally; they're gitignored by default (see ../../.gitignore)
unless you choose to track a specific file.
